# pit-protocol 🕳️

The P.I.T. Protocol — forkable **Public Information Transmission** for the public good · [publicinform.com](https://publicinform.com)

Turn any gathering's ephemeral knowledge into a permanent public good: **CRAWL → HARVEST → AUDIT → PUBLISH → CONSENT-FIRST GOVERNANCE**. CC0 — no rights reserved. Fork me like crazy. 🍴

## 🌐 The universal consent window (canon)

**consent@publicinform.com** — ONE consent window for every P.I.T. that will ever exist.

- **Takedown:** anyone in any pit's footage emails one word — `remove` — and they vanish from the archive. Prompt removal, no questions, no forms, honored with love (SLA ≤ 24h).
- **Permission grants** flow through the same door.
- **Forks inherit this address.** No pit runs its own consent inbox.
- The window is **checked every morning** — takedown requests never sleep in the inbox.

> "If we put content up that breaks the consent of the people we serve, they deserve an easy outlet to let us know as early as possible and they can be heard." — Shaka, 2026-07-29

Every manifest carries it (`consent.contact`), every page carries the notice (drop-in snippet: `ops/` + the consent kit), and revocation state lives in each pit's `data/consent-ledger.json` (`pit-consent-ledger/1`). Consent is a living door — it opens both ways, and it stays open. 🚪🦀
